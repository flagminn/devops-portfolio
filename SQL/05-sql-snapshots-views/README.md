# Виртуальные таблицы и снимки данных (Views)

## Описание бизнес-задачи
Проект направлен на изучение механизмов виртуализации данных с помощью представлений (`VIEWS`) и управления состоянием базы данных. Подробное описание задач приведено в файле [task.md](task.md).

## Стек технологий
- **PostgreSQL**
- **SQL** (CREATE VIEW, Materialization, Database State Management)

## Реализованные задачи
- Создание раздельных и комплексных представлений (`VIEWS`) для упрощения доступа к сложным выборкам.
- Хранение сгенерированных дат и состояний в виртуальных таблицах.
- Реализация механизмов материализации представлений и сброса состояния базы данных.

## Где найти решение
Все готовые скрипты и файлы с решениями находятся в подпапке `src/` данного проекта.
