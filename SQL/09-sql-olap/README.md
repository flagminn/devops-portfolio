# OLAP-анализ и оконные функции в SQL

## Описание бизнес-задачи
Проект посвящен использованию аналитических возможностей SQL (OLAP) и оконных функций для построения сложных отчетов и агрегации данных. Подробное описание задач приведено в файле [task.md](task.md).

## Стек технологий
- **PostgreSQL**
- **SQL** (OLAP, Window Functions, Aggregations, Analytics)

## Реализованные задачи
- Написание сложных аналитических запросов с использованием оконных функций (`ROW_NUMBER`, `RANK`, `SUM() OVER`, etc.).
- Построение многоуровневых отчетов и агрегаций для бизнес-аналитики.
- Оптимизация обработки больших объемов данных внутри реляционной базы.

## Где найти решение
All готовые скрипты и файлы с решениями находятся в подпапке `src/` данного проекта.
