# Контекст выполнения

Практическое применение DML-операций (`INSERT`, `UPDATE`, `DELETE`) и сложных соединений для модификации данных и поддержания актуальности базы.

**Схема базы данных:**
1. `pizzeria` (справочник пиццерий): `id`, `name`, `rating` (0–5).
2. `person` (справочник клиентов): `id`, `name`, `age`, `gender`, `address`.
3. `menu` (меню и цены): `id`, `pizzeria_id`, `pizza_name`, `price`.
4. `person_visits` (журнал посещений): `id`, `person_id`, `pizzeria_id`, `visit_date`.
5. `person_order` (журнал заказов): `id`, `person_id`, `menu_id`, `order_date`.
