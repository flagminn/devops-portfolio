# Модификация данных и продвинутые DML-операции

## Описание бизнес-задачи
Проект охватывает практические навыки изменения данных в базе (`INSERT`, `UPDATE`, `DELETE`) в сочетании с комплексными выборками. Подробное описание задач приведено в файле [task.md](task.md).

## Стек технологий
- **PostgreSQL**
- **SQL** (DML: INSERT, UPDATE, DELETE, Complex JOINs)

## Реализованные задачи
- Заполнение таблиц и модификация существующих записей на основе аналитических запросов.
- Сравнение визитов, заказов и ценовых категорий товаров с помощью составных условий.
- Автоматизация генерации данных и пакетное обновление цен и статусов клиентов.

## Где найти решение
Все готовые скрипты и файлы с решениями находятся в подпапке `src/` данного проекта.
