# Основы реляционной модели и SQL

## Описание бизнес-задачи
Проект направлен на освоение базовых концепций реляционных баз данных и написание первичных SQL-запросов для извлечения и фильтрации данных. Подробное описание и требования к выполнению задач приведены в файле [task.md](task.md).

## Стек технологий
- **PostgreSQL**
- **SQL** (ANSI SQL, DDL, DML, SELECT, WHERE, ORDER BY)

## Реализованные задачи
- Проектирование и создание базовой структуры реляционной базы данных.
- Написание простых `SELECT` запросов с условиями фильтрации (`WHERE`), сортировки (`ORDER BY`) и ограничения выдачи (`LIMIT`).
- Использование агрегирующих функций и базовых логических операторов для анализа данных в таблицах.

## Где найти решение
Все готовые скрипты и файлы с решениями находятся в подпапке `src/` данного проекта.
