# Индексирование и оптимизация производительности БД

## Описание бизнес-задачи
Проект посвящен настройке и оптимизации баз данных с помощью индексов для повышения производительности медленных SQL-запросов. Подробное описание и требования к выполнению задач приведены в файле [task.md](task.md).

## Стек технологий
- **PostgreSQL**
- **SQL** (Indexes, B-Tree, Functional Indexes, Multicolumn Indexes, EXPLAIN ANALYZE)

## Реализованные задачи
- Создание индексов для внешних ключей и часто используемых полей.
- Анализ планов выполнения запросов с помощью `EXPLAIN ANALYZE` для подтверждения эффективности индексов.
- Реализация составных, функциональных и частичных уникальных индексов под специфические бизнес-требования.

## Где найти решение
Все готовые скрипты и файлы с решениями находятся в подпапке `src/` данного проекта.
