# Работа с множествами и соединениями в SQL

## Описание бизнес-задачи
Проект посвящен продвинутым методам выборки данных, использованию операций над множествами (`UNION`, `INTERSECT`, `EXCEPT`) и базовым соединениям таблиц (`JOIN`). Подробное описание задач приведено в файле [task.md](task.md).

## Стек технологий
- **PostgreSQL**
- **SQL** (UNION, Subqueries, JOIN, NATURAL JOIN)

## Реализованные задачи
- Объединение результатов выборок с помощью множественных операторов и подзапросов.
- Поиск пересечений и разностей между наборами данных (multisets).
- Реализация базовых `JOIN` соединений и сравнение производительности различных подходов (`IN` vs `EXISTS`).

## Где найти решение
Все готовые скрипты и файлы с решениями находятся в подпапке `src/` данного проекта.
