# Пользовательские функции и хранимые процедуры в PostgreSQL

## Описание бизнес-задачи
Проект направлен на разработку серверной бизнес-логики с использованием пользовательских функций (User-Defined Functions) и хранимых процедур (Stored Procedures) на PL/pgSQL. Подробное описание задач приведено в файле [task.md](task.md).

## Стек технологий
- **PostgreSQL**
- **PL/pgSQL**, **SQL** (Functions, Stored Procedures, Procedural Logic)

## Реализованные задачи
- Разработка скалярных и табличных функций для инкапсуляции бизнес-правил.
- Написание хранимых процедур для пакетной обработки данных и управления транзакциями на стороне БД.
- Интеграция процедурного кода в архитектуру приложения.

## Где найти решение
Все готовые скрипты и файлы с решениями находятся в подпапке `src/` данного проекта.
