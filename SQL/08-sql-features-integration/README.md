# Интеграция расширенных функций и управление целостностью данных

## Описание бизнес-задачи
Проект направлен на улучшение клиентского опыта и поддержание целостности данных с помощью расширенных механизмов БД (скидки, аудит истории заказов, ограничения). Подробное описание задач приведено в файле [task.md](task.md).

## Стек технологий
- **PostgreSQL**
- **SQL** (Constraints, Triggers, Data Governance, Automated PK generation)

## Реализованные задачи
- Внедрение логики персональных и общих скидок для клиентов.
- Пересчет истории заказов и обеспечение строгой согласованности данных (`Data Consistency`).
- Применение правил управления данными (`Data Governance`) и автоматизация генерации первичных ключей.

## Где найти решение
Все готовые скрипты и файлы с решениями находятся в подпапке `src/` данного проекта.
