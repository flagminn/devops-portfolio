# Уровни изоляции транзакций и конкурентный доступ

## Описание бизнес-задачи
Проект исследует работу транзакций в условиях конкурентного доступа, уровни изоляции (`Read Committed`, `Repeatable Read`, `Serializable`) и возникающие аномалии. Подробное описание задач приведено в файле [task.md](task.md).

## Стек технологий
- **PostgreSQL**
- **SQL** (Transactions, Isolation Levels, Concurrency Control)

## Реализованные задачи
- Настройка и тестирование различных уровней изоляции транзакций.
- Воспроизведение и предотвращение классических аномалий并发 (грязное чтение, неповторяемое чтение, фантомное чтение).
- Обеспечение надежности и консистентности данных при одновременной работе нескольких сессий.

## Где найти решение
Все готовые скрипты и файлы с решениями находятся в подпапке `src/` данного проекта.
