# Углубленный анализ данных с использованием JOIN и CTE

## Описание бизнес-задачи
Проект продолжает изучение соединений таблиц, углубляясь в сложные типы `JOIN` (`LEFT`, `RIGHT`, `FULL OUTER JOIN`) и использование обобщенных табличных выражений (CTE). Подробное описание задач приведено в файле [task.md](task.md).

## Стек технологий
- **PostgreSQL**
- **SQL** (LEFT JOIN, RIGHT JOIN, FULL JOIN, CTE)

## Реализованные задачи
- Выявление пропусков данных и разрывов связей с помощью внешних соединений (`LEFT`/`RIGHT`/`FULL JOIN`).
- Рефакторинг сложных запросов с использованием CTE для улучшения читаемости и производительности.
- Решение прикладных аналитических задач по поиску предпочтений клиентов и оптимизации выборок.

## Где найти решение
Все готовые скрипты и файлы с решениями находятся в подпапке `src/` данного проекта.
