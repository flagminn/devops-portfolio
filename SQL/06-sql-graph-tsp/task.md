# Контекст выполнения

Моделирование графов и решение классической задачи коммивояжёра (TSP) с использованием рекурсивных SQL-запросов.

---

## Задание 00 — Classical TSP

| Параметр | Значение |
|---------------------------------|--|
| Директория для решений | `ex00` |
| Файлы для сдачи | `day05_ex00.sql` (или соответствующий `day06_ex00.sql` / `ex00`) |
| Используемый язык | ANSI SQL |

Напишите рекурсивный SQL-запрос для поиска гамильтонова цикла (тура) с минимальной суммарной стоимостью перемещения между узлами графа.

## Задание 01 — Opposite TSP

| Параметр | Значение |
|---------------------------------|--|
| Директория для решений | `ex01` |
| Файлы для сдачи | `ex01` |
| Используемый язык | ANSI SQL |

Модифицируйте рекурсивный запрос для поиска маршрута с максимальной стоимостью обхода графа.
