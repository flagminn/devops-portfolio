# Решение задачи коммивояжёра (TSP) средствами SQL

## Описание бизнес-задачи
Командный проект по моделированию графов и поиску оптимальных путей (решению классической задачи коммивояжёра) с использованием рекурсивных SQL-запросов. Подробное описание приведено в файле [task.md](task.md).

## Стек технологий
- **PostgreSQL**
- **SQL** (Recursive Queries, Graph Modeling, Combinatorial Optimization)

## Реализованные задачи
- Проектирование схемы базы данных для хранения графов (узлы и ребра с весами/стоимостью).
- Написание рекурсивных SQL-запросов для перебора гамильтоновых циклов (туров).
- Поиск маршрутов с минимальной и максимальной суммарной стоимостью путешествия.

## Где найти решение
Все готовые скрипты и файлы с решениями находятся в подпапке `src/` данного проекта.
