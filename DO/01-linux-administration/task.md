# Базовое администрирование операционных систем Linux

## Контекст выполнения
Проект направлен на практическое изучение базовых принципов работы с операционными системами Linux: развертывание ОС в виртуальной среде, управление пользователями и правами, конфигурирование сетевых интерфейсов, обновление системы, синхронизация времени, текстовые редакторы, управление службами через systemd, базовый мониторинг ресурсов и анализ логов.

## Task 1. Установка ОС
* Установите **Ubuntu 20.04 Server LTS** без графического интерфейса с помощью программы виртуализации **VirtualBox**.
* Проверьте версию установленной операционной системы с помощью команды `cat /etc/issue`.

## Task 2. Создание пользователя
* Создайте нового пользователя, отличного от системного, и добавьте его в группу `adm`.
* Проверьте наличие созданного пользователя в файле `/etc/passwd`.

## Task 3. Настройка сети ОС
* Установите сетевое имя машины в формате `user-1` и задайте актуальную временную зону.
* Выведите названия доступных сетевых интерфейсов с помощью консольных утилит.
* Получите IP-адрес сетевого интерфейса от DHCP-сервера.
* Определите внешний IP-адрес шлюза (`ip`) и локальный IP-адрес по умолчанию (`gw`).
* Настройте статическую конфигурацию сетевых параметров (IP, шлюз, публичные DNS-серверы 1.1.1.1 или 8.8.8.8).
* Перезагрузите виртуальную машину и убедитесь в корректности примененных статичных сетевых настроек.

## Task 4. Обновление ОС
* Выполните обновление системных пакетов операционной системы до актуальных версий.

## Task 5. Использование команды sudo
* Предоставьте созданному пользователю права на выполнение привилегированных команд через утилиту `sudo`.
* Проверьте корректность работы расширенных прав от имени нового пользователя.

## Task 6. Установка и настройка службы времени
* Настройте службу автоматической синхронизации времени (NTP) для поддержания актуального системного времени.

## Task 7. Установка и использование текстовых редакторов
* Установите консольный текстовый редактор **VIM**, а также два дополнительных на выбор (**NANO**, **MCEDIT**, **JOE** и др.).
* Создайте текстовые файлы `test_X.txt` (где X — название редактора), внесите в них свой никнейм и сохраните изменения.
* Откройте файлы повторно, измените содержимое на строку «21 School 21» и закройте без сохранения изменений.
* Выполните повторное редактирование файлов с демонстрацией функций поиска определенного слова и его последующей замены.

## Task 8. Установка и базовая настройка сервиса SSHD
* Установите службу **SSHd** и добавьте ее в автозагрузку системы.
* Перенастройте демон **SSHd** на прослушивание нестандартного порта `2022`.
* Проверьте наличие активного процесса `sshd` с помощью команды `ps` с необходимыми ключами фильтрации.
* Перезагрузите систему и проверьте доступность службы.

## Task 9. Установка и использование утилит top и htop
* Установите и запустите интерактивные утилиты мониторинга системных ресурсов **top** и **htop**.
* Зафиксируйте в выводе `top` время работы системы (uptime), количество активных процессов, загрузку процессора (CPU) и объем используемой памяти.
* Отсортируйте список процессов в **htop** по PID, проценту использования CPU (`PERCENT_CPU`), памяти (`PERCENT_MEM`) и времени работы (`TIME`).
* Выполните фильтрацию процессов по строке `sshd` и найдите системный процесс с PID `1`.

## Task 10. Использование утилиты fdisk
* Запустите команду `fdisk -l` для просмотра структуры жестких дисков и разделов.
* Зафиксируйте наименование жесткого диска, его емкость в гигабайтах, количество секторов и общий размер в байтах.

## Task 11. Использование утилиты df
* Выполните команду `df` для корневого раздела файловой системы, зафиксируйте общий размер, занятое и свободное пространство, а также процент заполнения.
* Выполните команду `df -Th` для вывода информации с указанием типов файловых систем и в человекочитаемом формате.

## Task 12. Использование утилиты du
* Выведите размер директорий `/home`, `/var` и `/var/log` в байтах и в человекочитаемом формате.
* Выведите размер каждого вложенного элемента внутри `/var/log` с помощью маски `*`.

## Task 13. Установка и использование утилиты ncdu
* Установите интерактивную утилиту анализа дискового пространства **ncdu**.
* Получите размеры директорий `/home`, `/var` и `/var/log` с помощью интерфейса `ncdu`.

## Task 14. Работа с системными журналами
* Откройте для просмотра и анализа системные лог-файлы: `/var/log/dmesg`, `/var/log/syslog` и `/var/log/auth.log`.
* Исследуйте структуру записей и найдите информацию о запуске службы SSHd и авторизации пользователей.

## Task 15. Использование планировщика заданий CRON
* Настройте периодический запуск команды `uptime` через планировщик системных заданий **CRON** с интервалом в 2 минуты.
* Проверьте факт выполнения запланированных задач в системных логах.
* Очистите список запланированных заданий **CRON**.
