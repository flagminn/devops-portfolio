- Объяснение наличие интерфейса lo: Интерфейс lo (loopback) — это виртуальный сетевой интерфейс, существующий только внутри машины. Он всегда имеет IP-адрес 127.0.0.1 (и ::1 в IPv6). Через lo процессы на одном компьютере могут общаться друг с другом по сети, например: веб-сервер → база данных, или curl http://localhost. Без lo не работали бы локальные сервисы, проверки здоровья (health checks), и даже вход в систему по SSH с localhost.

## Part 5. Использование команды **sudo**
- Значение команды Sudo. Команда sudo (superuser do) позволяет обычному пользователю временно выполнять команды с правами суперпользователя (root), не зная пароль root’а и не входя напрямую под root. Это повышает безопасность: Уменьшается риск случайного повреждения системы (человек работает как обычный пользователь 99% времени), Все действия с sudo логируются (/var/log/auth.log), что позволяет аудиторам отследить, кто и что изменил, Можно гибко настраивать права: например, разрешить пользователю только reboot, но не apt install.

- Перезапускаю SSH, чтобы применить изменения командой sudo systemctl restart ssh

- Ищу процесс SSHd в списке запущенных при помощи команды ps aux | grep sshd. Вывод![[Pasted image 20251129224737.png]]
- Объяснение значение команды и каждого ключа в ней: ps - process status - показывает работающие процессы; a - показать процессы всех пользователей (не только текущего); u - вывести в «пользовательском» формате: UID, CPU, MEM, команду; x - показать процессы без управляющего терминала (например, демоны, как sshd); | grep sshd - отфильтровать только строки, содержащие sshd

- значение столбцов вывода: USER - кто запустил процесс; PID - идентификатор процесса; %CPU, %MEM - нагрузка; VSZ, RSS - объём памяти; TTY - терминал; STAT - статус (Ss = sleeping + session leader); TIME - сколько процесс работал; COMMAND - команда, которой запущен процесс

- Перезапускаю систему командой sudo reboot

- Проверка автозапуска ![[Pasted image 20251129230227.png]]
- Проверка порта ![[Pasted image 20251129230409.png]]



- установил и запустил netstat![[Pasted image 20251129225949.png]]
- Расшифровка netstat - network statistics - показывает сетевые соединения, таблицы маршрутизации, статистику интерфейсов; -t - показать TCP-соединения; -a - показать все соединения (LISTEN, ESTABLISHED и т.д.); -n - показать цифры, а не имена (не ssh, а 2022) - быстрее и однозначно
- Столбцы вывода: Proto - протокол (tcp); Recv-Q - байт в очереди на чтение (0 = всё обработано); Send-Q - байт в очереди на отправку (0 = всё отправлено); Local Address - на какой IP и порт слушает сервер; 0.0.0.0:2022 - слушает на всех IPv4-интерфейсах (enp0s3, lo и т.д.); Foreign Address - откуда пришёл запрос (0.0.0.0:* в LISTEN - значит, ещё никто не подключился); State - состояние; LISTEN — готов принимать подключения;  0.0.0.0 означает: «принимать подключения на любом IPv4-адресе этого сервера». Если бы было 127.0.0.1:2022 — подключиться можно было бы только с localhost. 0.0.0.0 — значит, и с VirtualBox Host, и с других машин в сети (если настроить проброс портов).
