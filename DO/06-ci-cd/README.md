# Автоматизация CI/CD процессов с помощью GitLab CI

## Описание бизнес-задачи
Настройка автоматического пайплайна непрерывной интеграции и развертывания для проверки стиля кода, сборки и тестирования. 

Подробное техническое задание и требования к выполнению приведены в файле [task.md](task.md).

## Стек технологий
GitLab CI/CD, Bash, Make, Code Style (clang-format), Testing

## Реализованные задачи
- **Установка и настройка GitLab Runner:** Регистрация и подключение раннера к GitLab-репозиторию для выполнения CI/CD задач.
- **Автоматическая сборка (Build):** Описание стадий сборки проекта на языке C с использованием утилиты `make` в `.gitlab-ci.yml`.
- **Проверка кодстайла (Style):** Интеграция статического анализатора кода `clang-format` с жестким контролем ошибок (`--Werror`).
- **Интеграционное тестирование (Test):** Настройка автоматического прогона интеграционных и модульных тестов в пайплайне.
- **Автоматический деплой (Deploy):** Настройка безопасной доставки и развертывания артефактов на удаленный сервер по SSH.
- **Уведомления:** Интеграция системы оповещений о статусах сборочных пайплайнов в Telegram-мессенджер.

## Где найти решение
Все готовые конфигурационные файлы, скрипты и материалы решений находятся в подпапке [`src`](src) данного проекта.
