# Автоматизация CI/CD процессов с помощью GitLab CI

## Контекст выполнения
Проект направлен на построение базового пайплайна непрерывной интеграции и развертывания (**CI/CD**) с помощью **GitLab CI**: настройка раннеров, автоматизация сборки проекта на Си, проверка кодстайла, выполнение интеграционных тестов и деплой на удаленный сервер.

## Task 1. Настройка gitlab-runner
* Установите и зарегистрируйте **GitLab Runner** на виртуальной машине.
* Подключите раннер к репозиторию GitLab и переведите его в активный режим.

## Task 2. Сборка
* Напишите конфигурационный файл `.gitlab-ci.yml` с описанием стадии сборки (`stage: build`) проекта на языке C с использованием утилиты `make`.
* Проверьте успешность прохождения этапа сборки в интерфейсе GitLab.

## Task 3. Тест кодстайла
* Добавьте в пайплайн стадию проверки стиля кода (`stage: style`) с использованием утилиты `clang-format`.
* Настройте проверку на наличие ошибок форматирования (с опцией `--Werror`).

## Task 4. Интеграционные тесты
* Добавьте этап запуска интеграционных или модульных тестов (`stage: test`) для проверки корректности работы собранного приложения.

## Task 5. Этап деплоя
* Настройте стадию автоматического развертывания (`stage: deploy`) собранных артефактов на удаленный тестовый сервер по SSH.
* Ограничьте выполнение этапа деплоя по условиям или триггерам.

## Task 6. Дополнительно. Уведомления
* Настройте отправку уведомлений о статусе выполнения пайплайна в мессенджер (например, Telegram) через бота или вебхук.
