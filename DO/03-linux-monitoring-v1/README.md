# Разработка скриптов мониторинга и анализа состояния системы (v1.0)

## Описание бизнес-задачи
Автоматический сбор информации о системе, диагностика аппаратных ресурсов и анализ файловой структуры с помощью Bash-скриптов. 

Подробное техническое задание и требования к выполнению приведены в файле [task.md](task.md).

## Стек технологий
Linux, Bash, Shell, System Diagnostics, File System Analysis

## Реализованные задачи
- **Разработка Bash-скриптов:** Написание модульных скриптов на Bash для глубокого анализа состояния операционной системы.
- **Сбор системных метрик:** Автоматизированный сбор хостнейма, таймзоны, пользователя, версии ОС, uptime, IP-адреса, шлюза и параметров RAM / корневого раздела.
- **Цветовое оформление:** Реализация ANSI-форматирования вывода консоли с возможностью гибкой настройки цветов через внешний конфигурационный файл.
- **Анализ файловой системы:** Подсчет общего количества папок и файлов различных типов, поиск топ-5 самых больших директорий и топ-10 крупнейших файлов с указанием их веса.
- **Оптимизация производительности:** Измерение и вывод общего времени выполнения скрипта.

## Где найти решение
Все готовые конфигурационные файлы, скрипты и материалы решений находятся в подпапке [`src`](src) данного проекта.
