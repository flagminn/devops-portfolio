# Разработка скриптов мониторинга и анализа состояния системы (v1.0)

## Контекст выполнения
Проект направлен на автоматизацию сбора системной информации средствами языков командной оболочки **Bash** и **Shell**. Разрабатываемый скрипт должен собирать детальные метрики операционной системы, времени работы, сетевых параметров, состояния дискового пространства и выводить их в структурированном виде с настраиваемым цветовым оформлением.

## Task 1. Проба пера
* Создайте исполняемый скрипт на Bash, выводящий базовое приветствие и проверяющий окружение выполнения.

## Task 2. Исследование системы
* Реализуйте сбор и вывод следующих системных метрик:
  * Имя хоста операционной системы (`HOSTNAME`).
  * Текущий часовой пояс (название таймзоны и смещение).
  * Имя системного администратора (авторизованного пользователя).
  * Версия операционной системы (`OS`).
  * Время непрерывной работы системы (`UPTIME`).
  * Время непрерывной работы в секундах.
  * IP-адрес хоста в сети (порт/интерфейс по умолчанию).
  * Маска подсети и шлюз по умолчанию (`GATEWAY`).
  * Общий объем оперативной памяти (`RAM_TOTAL`), используемая (`RAM_USED`) и свободная (`RAM_FREE`) память в гигабайтах.
  * Общий объем корневого раздела (`SPACE_ROOT`), занятое (`SPACE_ROOT_USED`) и свободное (`SPACE_ROOT_FREE`) пространство в мегабайтах.

## Task 3. Визуальное оформление вывода для скрипта исследования системы
* Добавьте форматирование вывода метрик с использованием цветового оформления текста и фонов консоли (через escape-последовательности ANSI).
* Обеспечьте читаемость и аккуратное выравнивание параметров.

## Task 4. Конфигурирование визуального оформления вывода для скрипта исследования системы
* Реализуйте чтение параметров цветового оформления из внешнего конфигурационного файла (или через аргументы/параметры скрипта).
* Предусмотрите обработку ошибок некорректного выбора цветов и подстановку значений по умолчанию.

## Task 5. Исследование файловой системы
* Реализуйте сбор расширенной информации о файловой системе:
  * Общее количество папок (включая вложенные).
  * Топ-5 самых больших папок с указанием пути и размера.
  * Общее количество файлов всех типов (исполняемые, архивы, логи, текстовые файлы, символические ссылки).
  * Топ-10 самых больших файлов с указанием пути, размера и типа.
  * Время выполнения скрипта от начала до конца.
