# Система мониторинга, сбора метрик и алертинга

## Контекст выполнения
Проект направлен на развертывание стека мониторинга и наблюдаемости (**Observability**): сбор системных и прикладных метрик с помощью **Prometheus**, визуализация данных в **Grafana**, сбор логов через **Loki**, а также настройка правил алертинга с помощью **Alertmanager** при возникновении критических нагрузок.

## Task 1. Получение метрик и логов
* Разверните систему мониторинга **Prometheus** для сбора метрик с целевых сервисов.
* Настройте сборщик метрик контейнеров **cAdvisor** и агент **Node Exporter**.
* Подключите инструмент **Loki** для сбора текстовых логов работы приложений.

## Task 2. Визуализация
* Установите графический инструмент **Grafana** и подключите Prometheus и Loki в качестве источников данных (Data Sources).
* Создайте кастомные дашборды для отображения ключевых метрик использования процессора, памяти, дисковой подсистемы и сетевого трафика.

## Task 3. Отслеживание критических событий
* Настройте искусственную нагрузку на систему с помощью утилиты **stress** (по CPU, RAM, диску).
* Настройте правила алертинга (`Alerting rules`) в Prometheus / Alertmanager для отправки уведомлений при превышении пороговых значений нагрузки.
* Проверьте срабатывание алертов при достижении критических состояний системы.
