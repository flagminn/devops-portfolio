# Система мониторинга, сбора метрик и алертинга

## Описание бизнес-задачи
Развертывание стека мониторинга для сбора системных метрик, настройки дашбордов и оповещений об инцидентах. 

Подробное техническое задание и требования к выполнению приведены в файле [task.md](task.md).

## Стек технологий
Prometheus, Grafana, Alertmanager, cAdvisor, Stress, Nginx

## Реализованные задачи
- **Сбор метрик и логов:** Развертывание Prometheus, Node Exporter, cAdvisor и Loki для комплексного мониторинга инфраструктуры и сбора логов контейнеров.
- **Визуализация (Grafana):** Подключение источников данных и создание детальных дашбордов для мониторинга утилизации CPU, RAM, дисков и сети.
- **Нагрузочное тестирование:** Имитация пиковых нагрузок на систему с помощью утилиты `stress`.
- **Система алертинга:** Настройка правил оповещения в Prometheus / Alertmanager для оперативного реагирования при превышении критических порогов нагрузки.

## Где найти решение
Все готовые конфигурационные файлы, скрипты и материалы решений находятся в подпапке [`src`](src) данного проекта.
