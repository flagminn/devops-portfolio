# Контейнеризация веб-приложений с использованием Docker

## Описание бизнес-задачи
Упаковка мини-сервера и веб-приложения в изолированные контейнеры с использованием Dockerfile и оптимизацией образов. 

Подробное техническое задание и требования к выполнению приведены в файле [task.md](task.md).

## Стек технологий
Docker, Dockerfile, Nginx, FastCGI, Python / Go

## Реализованные задачи
- **Базовый Docker:** Запуск официального контейнера Nginx, управление жизненным циклом (запуск, просмотр логов, `docker exec`, экспорт/импорт).
- **Разработка мини-сервера:** Создание легковесного веб-приложения на бэкенде с проксированием запросов через Nginx.
- **Оптимизация Dockerfile:** Написание кастомных Dockerfile с использованием multi-stage сборки и легковесных базовых образов (Alpine) для минимизации размера контейнера.
- **Линтинг безопасности (Dockle):** Проверка образов на уязвимости и соответствие best practices, устранение найденных замечаний.
- **Docker Compose:** Конфигурирование многоконтейнерной инфраструктуры с помощью `docker-compose.yml`.

## Где найти решение
Все готовые конфигурационные файлы, скрипты и материалы решений находятся в подпапке [`src`](src) данного проекта.
