# Контейнеризация веб-приложений с использованием Docker

## Контекст выполнения
Проект направлен на освоение базовых принципов контейнеризации с помощью **Docker**: создание кастомных Dockerfile, сборка образов веб-серверов и приложений, управление контейнерами, оптимизация размеров образов и проверка их безопасности с помощью утилиты **Dockle**.

## Task 1. Готовый докер
* Скачайте официальный Docker-образ с сервером Nginx.
* Запустите контейнер в фоновом режиме на порту 80 с пробросом на хост-машину.
* Проверьте работу контейнера с помощью `docker ps` и обратитесь к странице приветствия через `curl`.
* Остановите и удалите созданный контейнер.

## Task 2. Операции с контейнером
* Запустите контейнер Nginx в интерактивным режиме или в фоне.
* Просмотрите логи работы контейнера с помощью `docker logs`.
* Зайдите внутрь контейнера через командную оболочку `docker exec -it <container_id> bash`.
* Экспортируйте контейнер в архив (`docker export`) и импортируйте его обратно (`docker import`).

## Task 3. Мини веб-сервер
* Напишите простой мини веб-сервер (например, на Python или Go), который возвращает простую HTML-страничку.
* Напишите собственный **Dockerfile**, который собирает приложение, запускает мини-сервер и проксирует запросы через Nginx (или обрабатывает напрямую через FastCGI).
* Соберите Docker-образ и протестируйте его работу.

## Task 4. Свой докер
* Напишите оптимизированный `Dockerfile` для запуска написанного мини-сервера.
* Минимизируйте размер результирующего Docker-образа за счет использования multi-stage сборки или легких базовых образов (например, `alpine`).

## Task 5. Dockle
* Проверьте полученный Docker-образ на наличие уязвимостей и соблюдение best practices с помощью утилиты линтинга **Dockle**.
* Устраните выявленные замечания и добейтесь прохождения проверки без критических ошибок.

## Task 6. Базовый Docker Compose
* Создайте конфигурационный файл `docker-compose.yml` для совместного запуска веб-сервера и разработанного приложения.
* Проверьте запуск многоконтейнерной системы с помощью `docker-compose up`.
