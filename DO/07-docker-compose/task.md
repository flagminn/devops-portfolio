# Оркестрация многоконтейнерных приложений с помощью Docker Compose

## Контекст выполнения
Проект направлен на освоение инструментов совместного запуска и оркестрации контейнеров с помощью **Docker Compose** и базовое знакомство с кластеризацией **Docker Swarm** в связке с виртуализацией **Vagrant**.

## Task 1. Запуск нескольких Docker-контейнеров с использованием Docker Compose
* Создайте многоконтейнерную архитектуру (например, веб-сервер Nginx + бэкенд-приложение на Python/Go + база данных PostgreSQL).
* Напишите конфигурационный файл `docker-compose.yml`, описывающий сервисы, сети, тома (`volumes`) и переменные окружения.
* Запустите систему с помощью команды `docker-compose up -d` и проверьте доступность сервисов.

## Task 2. Создание виртуальных машин
* Установите и настройте инструмент **Vagrant**.
* Напишите конфигурационный файл `Vagrantfile` для быстрого развертывания нескольких виртуальных машин, которые будут использоваться в качестве узлов кластера.

## Task 3. Создание простейшего Docker Swarm
* Объедините созданные с помощью Vagrant виртуальные машины в единый кластер **Docker Swarm** (один менеджер и один или несколько воркеров).
* Разверните в созданном кластере сервисы с использованием механизмов репликации и балансировки нагрузки.
