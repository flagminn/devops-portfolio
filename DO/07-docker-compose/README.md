# Оркестрация многоконтейнерных приложений с помощью Docker Compose

## Описание бизнес-задачи
Развертывание связанной архитектуры микросервисов (бэкенд, база данных, прокси-сервер) с использованием Docker Compose. 

Подробное техническое задание и требования к выполнению приведены в файле [task.md](task.md).

## Стек технологий
Docker Compose, Nginx, PostgreSQL, Flask / Go, Multi-container

## Реализованные задачи
- **Многоконтейнерная оркестрация:** Проектирование и запуск связанной архитектуры (веб-сервер Nginx + бэкенд + БД PostgreSQL) через `docker-compose.yml`.
- **Управление сетями и томами:** Настройка изолированных сетей Docker и персистентных томов (`volumes`) для хранения данных.
- **Виртуализация (Vagrant):** Написание конфигурационного файла `Vagrantfile` для быстрого развертывания виртуальных машин под тестовое окружение.
- **Docker Swarm:** Объединение виртуальных узлов в кластер Docker Swarm, настройка репликации и балансировки нагрузки сервисов.

## Где найти решение
Все готовые конфигурационные файлы, скрипты и материалы решений находятся в подпапке [`src`](src) данного проекта.
