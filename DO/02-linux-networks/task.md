# Настройка и диагностика сетевых интерфейсов и маршрутизации в Linux

## Контекст выполнения
Проект направлен на углубленное изучение стека протоколов TCP/IP, механизмов IP-адресации, статической и динамической маршрутизации, анализа сетевого трафика, проверки пропускной способности каналов, настройки межсетевых экранов, NAT и туннелирования в операционных системах Linux.

## Task 1. Инструмент ipcalc
* Поднимите утилиту **ipcalc** и выполните анализ параметров сети для заданных IP-адресов и масок.
* Определите и зафиксируйте сетевой адрес для IP `192.167.38.54` с маской `255.255.255.0` (а также префиксом `/24` и двоичной маской).
* Вычислите диапазон доступных хостов (доступные IP-адреса) для подсети `12.167.38.4` с маской `255.255.255.248` (префикс `/29`).
* Проведите расчеты для сетей с префиксами `/15`, `255.255.255.0`, `10.0.0.0/8` и т.д. в соответствии со спецификацией.

## Task 2. Статическая маршрутизация между двумя машинами
* Настройте статическую маршрутизацию между двумя виртуальными машинами.
* Задайте статические IP-адреса для интерфейсов обеих машин (например, `192.168.100.10` и `192.168.100.20` с маской `/24`).
* Добавьте статический маршрут вручную с помощью команды `ip route add` или конфигурационных файлов сети (`netplan`).
* Проверьте доступность узлов с помощью утилиты `ping`.

## Task 3. Утилита iperf3
* Установите утилиту измерения пропускной способности сети **iperf3**.
* Измерьте скорость соединения между двумя виртуальными машинами в мегабитах в секунду (Mbps) и мегабайтах в секунду (MB/s).

## Task 4. Сетевой экран
* Настройте правила межсетевого экрана **UFW** (или `iptables`) на обеих виртуальных машинах.
* Заблокируйте или разрешите входящие/исходящие соединения для определенных портов и IP-адресов.
* Проверьте работу правил с помощью утилиты `ping` и попыток подключения к заблокированным портам.

## Task 5. Статическая маршрутизация сети
* Разверните топологию сети, состоящую из четырех виртуальных машин (две рабочие станции и два роутера/шлюза).
* Настройте статическую маршрутизацию на роутерах для обеспечения связанности между изолированными подсетями.
* Проверьте прохождение маршрутов с помощью утилиты `traceroute` (или `ip route get`).

## Task 6. Динамическая настройка IP с помощью DHCP
* Настройте службу **DHCP** (например, `isc-dhcp-server` или `dnsmasq`) на одном из роутеров.
* Настройте выдачу IP-адресов клиентам по MAC-адресам (статическое связывание на уровне DHCP).
* Проверьте автоматическое получение сетевых настроек на клиентской машине.

## Task 7. NAT
* Настройте трансляцию сетевых адресов (**NAT** / **Source NAT** / **Masquerading**) на шлюзе для обеспечения доступа клиентов из изолированной внутренней сети во внешнюю сеть (Интернет).
* Проверьте доступность внешних ресурсов из внутренней сети и зафиксируйте подмену IP-адресов источника.

## Task 8. Дополнительно. Знакомство с SSH Tunnels
* Изучите механизмы проброса портов и создания защищенных туннелей с помощью **SSH** (`Local Port Forwarding` и `Remote Port Forwarding`).
* Продемонстрируйте безопасное подключение к удаленному сервису через зашифрованный SSH-туннель.
