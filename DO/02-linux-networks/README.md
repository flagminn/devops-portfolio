# Настройка и диагностика сетевых интерфейсов и маршрутизации в Linux

## Описание бизнес-задачи
Конфигурация сетевых параметров, статическая и динамическая маршрутизация, тестирование пропускной способности и настройка межсетевых экранов. 

Подробное техническое задание и требования к выполнению приведены в файле [task.md](task.md).

## Стек технологий
Linux, TCP/IP, ipcalc, iperf3, UFW/iptables, DHCP, NAT, SSH Tunnels

## Реализованные задачи
- **Анализ IP-адресации:** Выполнение расчетов подсетей, масок, префиксов и доступных диапазонов хостов с помощью утилиты `ipcalc`.
- **Статическая маршрутизация:** Настройка статической маршрутизации между виртуальными машинами и связности изолированных подсетей через роутеры с проверкой через `traceroute`.
- **Пропускная способность сети:** Измерение сетевой скорости и производительности каналов с помощью утилиты `iperf3`.
- **Межсетевой экран:** Конфигурирование правил фильтрации трафика с помощью UFW / iptables.
- **Динамическая конфигурация (DHCP):** Развертывание и настройка DHCP-сервера для автоматической выдачи IP-адресов клиентам по MAC-адресам.
- **NAT:** Настройка трансляции сетевых адресов (Masquerading / Source NAT) для обеспечения доступа внутренней сети в Интернет.
- **SSH Туннелирование:** Практическое освоение механизмов Local и Remote Port Forwarding для безопасного проброса портов.
