# Углубленный системный мониторинг, анализ логов и метрик (v2.0)

## Описание бизнес-задачи
Мониторинг производительности в реальном времени, генерация нагрузки и логов, анализ веб-трафика и визуализация метрик. 

Подробное техническое задание и требования к выполнению приведены в файле [task.md](task.md).

## Стек технологий
Linux, GoAccess, Prometheus, Grafana, Node Exporter, Bash

## Реализованные задачи
- **Генерация и заполнение файловой системы:** Написание скриптов для автоматического создания файлов заданной структуры и размера с целью тестирования дисковой подсистемы.
- **Управление очисткой:** Реализация алгоритмов удаления и очистки сгенерированных файлов по дате, маске и логам.
- **Генерация веб-логов:** Создание симулятора логов сервера в формате Apache/Nginx Combined со случайными IP, статус-кодами (200, 404, 500 и др.) и URL.
- **Анализ логов (GoAccess):** Установка и настройка анализатора веб-трафика GoAccess для интерактивного просмотра и генерации HTML-отчетов.
- **Стек мониторинга (Prometheus & Grafana):** Развертывание Prometheus, Node Exporter и Grafana для сбора и дашбординга системных метрик.
- **Нагрузочное тестирование:** Проведение стресс-тестирования утилитой `stress` с фиксацией всплесков нагрузки в реальном времени.
- **Кастомный экспортер:** Разработка собственного легковесного скрипта-экспортера метрик для Prometheus.

## Где найти решение
Все готовые конфигурационные файлы, скрипты и материалы решений находятся в подпапке [`src`](src) данного проекта.
