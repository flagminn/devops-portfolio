# Углубленный системный мониторинг, анализ логов и метрик (v2.0)

## Контекст выполнения
Проект направлен на расширенную автоматизацию администрирования Linux: создание искусственной нагрузки на файловую систему, генерацию логов веб-серверов, сбор метрик с помощью **Prometheus**, визуализацию в **Grafana**, а также анализ веб-трафика с помощью утилиты **GoAccess**.

## Task 1. Генератор файлов
* Напишите Bash-скрипт для генерации файлов в указанной директории по заданным параметрам (суффикс названия, количество букв в имени, максимальный размер в мегабайтах).

## Task 2. Засорение файловой системы
* Запустите генератор для заполнения файловой системы до заданного уровня заполнения (контроль через `df`), учитывая ограничения на свободное место.

## Task 3. Очистка файловой системы
* Напишите скрипт для очистки созданных файлов по заданным критериям (по дате создания, по маске имени, по логам создания).

## Task 4. Генератор логов
* Создайте скрипт генерации логов доступа веб-сервера (в формате **Apache/Nginx Combined**) за несколько дней, содержащий случайные IP-адреса, коды ответа (200, 401, 403, 404, 500, 502, 503), агенты пользователей и URL.

## Task 5. Мониторинг
* Соберите и проанализируйте метрики работы системы с помощью встроенных утилит и скриптов мониторинга.

## Task 6. GoAccess
* Установите и запустите анализатор логов веб-сервера **GoAccess** для обработки сгенерированных логов (в режиме консоли и генерации HTML-отчетов).

## Task 7. Prometheus и Grafana
* Установите систему мониторинга **Prometheus** и агент сбора метрик **Node Exporter**.
* Установите графический интерфейс визуализации **Grafana** и подключите Prometheus в качестве источника данных.

## Task 8. Готовый дашборд
* Создайте или импортируйте готовый дашборд в Grafana для отображения ключевых системных метрик (CPU, RAM, диск, сеть).
* Проведите нагрузочное тестирование с помощью утилиты `stress` и зафиксируйте всплески метрик на графиках Grafana.

## Task 9. Дополнительно. Свой node_exporter
* Разработайте собственный легковесный скрипт-экспортер метрик в формате, совместимом с Prometheus, для мониторинга специфического параметра системы.
