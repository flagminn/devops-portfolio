# Многопользовательский REST-сервис игры с БД и авторизацией

## Описание бизнес-задачи
Расширение веб-приложения «Крестики-Нолики» на базе Flask: интеграция реляционной базы данных PostgreSQL с помощью SQLAlchemy, внедрение механизмов аутентификации (HTTP Basic Auth) и расширение игровой логики до полноценного мультиплеера между пользователями и ИИ.

Подробное описание требований и условий задач см. в файле [task.md](task.md).

## Стек технологий
- **Язык программирования:** Python 3
- **Веб-фреймворк:** Flask
- **База данных и ORM:** PostgreSQL, SQLAlchemy
- **Безопасность:** HTTP Basic Authentication, шифрование учетных данных, защита эндпоинтов.
- **Архитектура:** Многослойная архитектура (Layered/Clean Architecture).

## Реализованные задачи
1. **Интеграция с БД (PostgreSQL):** Подключение SQLAlchemy ORM, замена in-memory хранилища на персистентное хранение сущностей.
2. **Аутентификация и авторизация:** Реализация регистрации пользователей, HTTP Basic Auth, механизма `UserAuthenticator` и защита REST API эндпоинтов.
3. **Мультиплеер и логика игр:** 
   - Поддержка состояний матча (ожидание, ход игрока, победа, ничья).
   - Эндпоинты для создания игр (vs ИИ или пользователь), присоединения к играм, получения списка матчей и детальной информации.
