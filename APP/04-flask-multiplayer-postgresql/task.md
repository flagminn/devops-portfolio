# Task.md

## Контекст выполнения
Проект развивается на базе предыдущей реализации Flask-приложения «Крестики-Нолики». Требуется интегрировать реляционную базу данных PostgreSQL через SQLAlchemy, внедрить систему аутентификации пользователей (HTTP Basic Auth) и расширить игровую логику до поддержки мультиплеера (игра между двумя пользователями или с ИИ).

---

## Task 1. Добавление базы данных
- Интегрировать реляционную СУБД PostgreSQL с использованием ORM **SQLAlchemy**.
- Заменить локальное потокобезопасное in-memory хранилище на персистентное хранение в базе данных.
- Описать ORM-модели с необходимыми аннотациями и связями.

---

## Task 2. Добавление авторизации
- Реализовать сущность пользователя (UUID, логин, пароль) и распространить ее поддержку на все архитектурные слои.
- Создать модель `SignUpRequest` для регистрации.
- Реализовать `UserService` и сервис авторизации:
  - Регистрация новых пользователей.
  - Аутентификация по заголовку `Authorization` (Base64 `login:password`).
- Реализовать контроллеры авторизации и механизм защиты эндпоинтов (`UserAuthenticator`):
  - Проверка учетных данных, возврат кода `401 Unauthorized` при ошибке.
  - Открытие доступа без авторизации только к эндпоинтам регистрации и входа.

---

## Task 3. Добавление логики игры между двумя игроками
- Расширить состояния игровой сессии: ожидание игроков, ход конкретного игрока (по UUID), ничья, победа игрока.
- Добавить распределение игровых значков (крестики/нолики).
- Реализовать расширенный набор REST API эндпоинтов:
  - Создание новой игры (против ИИ или другого игрока).
  - Получение списка доступных игр.
  - Присоединение к существующей игре.
  - Обновление текущего состояния игры (ход игрока).
  - Получение информации о текущей игре.
  - Получение информации о пользователе по UUID.
