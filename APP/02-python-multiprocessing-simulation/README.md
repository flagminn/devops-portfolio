# Симуляция экзамена и сетевые утилиты на Python

## Описание бизнес-задачи
Проект включает в себя многопроцессорную симуляцию экзаменационного процесса с динамическим обновлением состояния в терминале, а также сетевые скрипты и утилиты на Python. Реализована сложная вероятностная модель поведения участников, параллельная обработка задач и синхронизация процессов.

Подробное описание требований и условий задач см. в файле [task.md](task.md).

## Стек технологий
- **Язык программирования:** Python 3
- **Концепции:** Многопроцессорность (`multiprocessing`), параллельные вычисления, синхронизация процессов, динамический вывод в консоль, парсинг файлов, вероятностное моделирование.

## Решенные задачи
1. **Многопроцессорная симуляция экзамена:**
   - Моделирование параллельной работы экзаменаторов в отдельных процессах.
   - Управление общей очередью студентов и учет обеденных перерывов экзаменаторов.
   - Вероятностный выбор ответов по закону золотого сечения с учетом гендерной специфики.
   - Динамический вывод статусов в реальном времени и подробная итоговая статистика.
2. **Сетевые и прикладные утилиты:**
   - Набор вспомогательных скриптов для работы с сетевыми запросами и загрузкой данных.

## Где найти решение
Все исходные скрипты и конфигурации решений расположены в поддиректории [`src`](src).
