# REST-сервис игры «Крестики-Нолики» на Flask

## Описание бизнес-задачи
Разработка бэкенд веб-приложения на Flask, реализующего логику игры «Крестики-Нолики» против искусственного интеллекта (алгоритм «Минимакс»). Архитектура приложения строго разделена на изолированные слои (Web, Domain, Datasource, DI) с поддержкой одновременных сессий нескольких игроков.

Подробное описание требований и условий задач см. в файле [task.md](task.md).

## Стек технологий
- **Язык программирования:** Python 3
- **Веб-фреймворк:** Flask
- **Архитектура:** Многослойная архитектура (Layered/Clean Architecture), Dependency Injection, Singleton.
- **Алгоритмы:** Алгоритм «Минимакс» для принятия решений ИИ.

## Реализованные задачи
1. **Многослойная архитектура:** Проектирование и разделение кода на слои `web`, `domain`, `datasource` и `di`.
2. **Бизнес-логика (Domain):** Создание моделей игрового поля и сессий, реализация алгоритма «Минимакс» и валидации ходов.
3. **Хранение данных (Datasource):** Реализация потокобезопасного in-memory хранилища и репозитория сессий с маппингом данных.
4. **Веб-интерфейс (Web):** Создание REST API на Flask для обработки игровых ходов (`POST /game/{uuid}`) с обработкой ошибок.
5. **Внедрение зависимостей (DI):** Реализация контейнера зависимостей для управления жизненным циклом компонентов.

## Где найти решение
Все исходные скрипты и конфигурации решений расположены в поддиректории [`src`](src).
