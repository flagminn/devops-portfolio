# Task.md

## Контекст выполнения
Проект представляет собой комплекс задач по базовой алгоритмической подготовке на языке Python. В рамках заданий отрабатываются навыки работы со стандартными потоками ввода-вывода (`stdin`/`stdout`), обработки файлов, работы с матрицами, структурами данных (словари, списки), динамического программирования и реализации базовых математических и алгоритмических вычислений без использования встроенных высокоуровневых функций.

## Task 1. Скалярное произведение
Вычислить скалярное произведение двух векторов в трехмерном пространстве.

- **Входные данные:** Вещественные числа, координаты двух векторов на двух строках соответственно.
- **Выходные данные:** Вещественное число — скалярное произведение данных векторов.

| Входные данные | Выходные данные |
| :--- | :--- |
| `1.0 2.0 3.0`<br>`4.0 5.0 6.0` | `32.0` |

## Task 5. Преобразование строки в число
Преобразовать строку в вещественное число без использования функции `float()` или аналогичных встроенных средств. Умножить полученное число на 2 и вывести результат с тремя знаками после запятой. Требуется проверка корректности ввода.

| Входные данные | Выходные данные |

## Task 6. Фильмы
Объединить два отсортированных по полю `year` списка фильмов в формате JSON так, чтобы итоговый список остался отсортированным.

- **Входные данные:** Файл `input.txt` с JSON-структурой из двух списков фильмов.
- **Выходные данные:** Объединенный JSON-список `list0` (или сообщение об ошибке / «Empty file»).

### Пример входных данных (`input.txt`):
```json
{
  "list1": [
    { "title": "Titanic", "year": 1998 },
    { "title": "Taxi 2", "year": 2000 },
    { "title": "Avatar", "year": 2009 }
  ],
  "list2": [
    { "title": "Terminator", "year": 1984 },
    { "title": "Home Alone", "year": 1993 },
    { "title": "Spider-Man", "year": 2002 }
  ]
}
```

### Пример выходных данных:
```json
{
  "list0": [
    { "title": "Terminator", "year": 1984 },
    { "title": "Home Alone", "year": 1993 },
    { "title": "Titanic", "year": 1998 },
    { "title": "Taxi 2", "year": 2000 },
    { "title": "Spider-Man", "year": 2002 },
    { "title": "Avatar", "year": 2009 }
  ]
}
```

## Task 7. Робот

- **Входные данные:** Размеры поля $N$ и $M$, затем $N$ строк по $M$ неотрицательных чисел (монеты в клетках).

| Входные данные | Выходные данные |
| :--- | :--- |
| `3 4`<br>`3 0 2 1`<br>`6 4 8 5`<br>`3 3 6 0` | `27` |

## Task 9. Производная в точке
Вычислить значение производной заданного полинома в указанной точке. Результат выводится с точностью до трех знаков после запятой.

- **Входные данные:** Старшая степень полинома $N$ и точка вычисления $x$, затем $N+1$ строка с коэффициентами полинома от старшей степени к младшей.
- **Выходные данные:** Вещественное число с 3 знаками после точки — значение производной в точке.

| Входные данные | Выходные данные |
| :--- | :--- |
| `2 3.0`<br>`5`<br>`1.2`<br>`-3` | `31.200` |

## Task 10. Аппараты
Выбрать пару аппаратов одинакового года выпуска с минимальной суммарной стоимостью, суммарное время работы которых не меньше требуемого. Гарантируется существование единственного решения.

- **Входные данные:** Количество доступных аппаратов $N$ и требуемое время работы, затем $N$ строк с параметрами аппаратов: год выпуска, стоимость, время работы.
- **Выходные данные:** Натуральное число — минимальная общая стоимость выбранных аппаратов (либо сообщение об ошибке при некорректном вводе).

| Входные данные | Выходные данные |
| :--- | :--- |
| `5 48`<br>`2023 100 14`<br>`2020 18 347`<br>`2023 10000000 34`<br>`2023 1000 34`<br>`2022 10 34` | `1100` |
