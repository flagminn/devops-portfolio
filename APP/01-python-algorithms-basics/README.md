# Решение алгоритмических задач на Python

## Описание бизнес-задачи
Набор инфраструктурных и прикладных алгоритмических задач на языке Python, направленных на отработку навыков работы с потоками ввода-вывода, структурами данных, матрицами и динамическим программированием без применения сторонних высокоуровневых библиотек. 

Подробное описание требований и условий задач см. в файле [task.md](task.md).

## Стек технологий
- **Язык программирования:** Python 3
- **Концепции:** Стандартные потоки ввода-вывода (`stdin`/`stdout`), парсинг JSON, обработка двумерных массивов (матриц), алгоритмы динамического программирования, базовая валидация данных.

## Реализованные задачи
В рамках проекта решены следующие практические задачи:
1. **Скалярное произведение векторов:** Вычисление скалярного произведения в 3D-пространстве.
2. **Проверка палиндрома:** Алгоритмическое определение палиндрома для чисел без использования строковых преобразований.
3. **Анализ геометрических фигур:** Подсчет количества прямоугольников и кругов в бинарной матрице.
4. **Треугольник Паскаля:** Генерация строк треугольника Паскаля с валидацией входных параметров.
5. **Парсинг чисел:** Реализация ручного преобразования строки в вещественное число без использования встроенной функции `float()`.
6. **Слияние списков фильмов:** Объединение и сортировка структурированных данных из JSON-формата.
7. **Поиск оптимального маршрута робота:** Задача динамического программирования на нахождение максимальной суммы монет в сетке.
8. **Подсчет уникальных значений:** Фильтрация и подсчет уникальных элементов в потоке чисел.
9. **Вычисление производной:** Нахождение значения производной многочлена в заданной точке.
10. **Оптимизация подбора оборудования:** Выбор пары аппаратов с заданными характеристиками надежности и стоимости.
